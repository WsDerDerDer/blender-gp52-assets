# 场景 / Scenes

场景模板与坐标/参数约定。每个场景一个子目录，含场景 README（坐标约定、参数范围、可调项），必要时附场景渲染样张。

## 已入库

- [沙滩海岸](沙滩海岸/) — 沙滩 + 海洋双区场景

## 场景模板结构

```
场景/<场景名>/
├── README.md      # 坐标约定、参数范围、可调项
├── preview/       # 渲染样张（可选）
└── <素材文件>      # spec / 生成脚本（可选）
```

## 通用约定

- 程序化生成对象需在 Geometry Nodes 修饰器面板提供可调参数（长宽、分辨率、噪声尺寸等）
- 静态元素（背景/铺子/橱窗/招牌/黑板/bokeh）用主 GP 对象 1 关键帧；动态元素（灯笼/萤火虫/粒子/倒影/光晕）用独立 GP 对象逐帧重画
